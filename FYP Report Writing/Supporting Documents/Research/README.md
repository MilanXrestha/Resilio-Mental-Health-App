# RESEARCH AND CROSS-CUTTING DOCUMENTS

This folder contains documents that span multiple RUP phases or are used as reference material throughout the entire project. They are not specific to a single phase.

---

## Documents in This Folder

| File | Contents | Report Reference |
|---|---|---|
| `RUP_Phase_Artefacts.md` | Master list of every artefact produced in each RUP phase (Inception → Elaboration → Construction → Transition); maps artefacts to their evidence location and report section | All chapters |
| `Research_Papers_and_Journals.md` | 50+ academic sources organised by theme: Nepal mental health, digital mental health, clinical instruments (PHQ-9, GAD-7), mindfulness apps, telepsychology, software engineering, Nepal digital infrastructure, app comparisons, legal/compliance, future work | Chapter 2; References |
| `Survey_Instruments_and_Analysis.md` | Pre-survey (166 responses, Inception) and post-survey (132 responses, Transition); complete raw percentage breakdowns for all 20 questions; design decision mapping; pre vs post comparison table | Chapter 1, Section 1.3; Chapter 4, Section 4.4; Appendices G and H |
| `Weekly_Progress_Log.md` | Task-by-task log for all 20 project weeks across all 4 RUP phases; maps actual delivery to the planned RUP schedule | Chapter 3 (methodology evidence) |

---

## Why These Are Cross-Cutting

| Document | Spans Multiple Phases Because |
|---|---|
| `RUP_Phase_Artefacts.md` | Provides the complete artefact inventory — the lens through which all other documents are understood |
| `Research_Papers_and_Journals.md` | Literature informed Inception (problem validation), Elaboration (design decisions), and Construction (implementation choices) |
| `Survey_Instruments_and_Analysis.md` | Pre-survey is an Inception artefact; post-survey is a Transition artefact; both are analysed together for the comparison |
| `Weekly_Progress_Log.md` | Documents actual weekly progress against the plan — spans all 20 weeks |
