# PHASE 1: INCEPTION — FEASIBILITY STUDY
**RUP Phase:** Inception | **Weeks:** 1–5 | **Dates:** November 2024

---

## Phase Objective

Establish the project's business case, validate the problem domain through research and surveys, identify all stakeholders, assess technical and economic feasibility, select the development methodology, and set up the full project environment.

## Key Decisions Made This Phase

- **Methodology:** RUP selected (see `Supporting Documents/01_RUP_Phase_Artefacts.md` and Appendix E)
- **Authentication:** SuperTokens OTP (passwordless) + Google + Facebook Sign-In
- **Payment:** eSewa only — removes credit card barrier for Nepali users
- **Platform:** Android-first; iOS deferred due to App Store compliance timeline
- **Architecture:** Flutter (frontend) + Node.js/Express (backend) + Supabase/PostgreSQL (database)
