## Pre-Survey Key Findings (166 Responses)

| Finding | % | Design Impact |
|---|---|---|
| Experience stress/low mood often or always | 77.1% | Validates the problem scale |
| Cost is biggest barrier | 38.0% | eSewa integration as priority |
| Never retained a mental health app | 80.8% | Achievement/engagement system needed |
| Offline capability important | 80.8% | SQLite offline architecture required |
| Willing to pay via eSewa | 60.9% | eSewa validated as payment method |
| Access to real therapist most valued | 38.6% | Therapist module as core feature |

## Feasibility Summary

| Dimension | Verdict | Rationale |
|---|---|---|
| Technical | Feasible | Flutter, Node.js, Supabase, SuperTokens, WebRTC, eSewa all have stable SDKs |
| Economic | Feasible | Free tiers on Supabase, SuperTokens, Firebase, Cloudinary cover FYP scope |
| Operational | Feasible | Solo developer with 20 weeks; scope bounded to three user roles |
| Schedule | Feasible | 7 construction iterations fit within 11-week window |
